API de gestão de consultas médicas

Sistema REST para cadastro, consulta e acompanhamento de profissionais da saúde e de agendamentos médicos, com foco em segurança, documentação e preparação para produção.

Abrir documentação Ver profissionais no Swagger

Funcionalidades

  • CRUD de profissionais
  • CRUD de consultas
  • Busca por profissional
  • Autenticação por API Key
  • CORS e logs de acesso

Endpoints

  • /api/v1/professionals/
  • /api/v1/appointments/
  • /api/v1/professionals/<id>/appointments/
  • /api/docs/

Segurança

A API exige autenticação via header X-API-KEY ou Api-Key, com validação e proteção de rotas por permissão explícita.

Painel de teste

Informe a API key de desenvolvimento para consultar os endpoints protegidos.
